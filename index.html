🔧 Setting Up Google Sign-In
You need a free Google Cloud Client ID to enable Google Drive sync. Takes ~3 minutes:
1
Go to console.cloud.google.com → Create a new project named BudgetOS
2
Go to APIs & Services → Enable APIs → Enable Google Sheets API and Google Drive API
3
Go to OAuth Consent Screen → External → Add your Gmail as test user
4
Go to Credentials → Create → OAuth 2.0 Client ID → Web application → Add your file's URL to Authorized Origins
5
Copy the Client ID (ends in .apps.googleusercontent.com) and paste it in the app
